Accessibility Statement

Our commitment to web accessibility

Our Commitment

St.Francis Technical Training Institute is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone.

Accessibility Standards

This website conforms to WCAG 2.1 Level AA guidelines, which defines levels of accessibility to ensure content is accessible to the widest audience possible.

Features

Our website includes the following accessibility features:

  • Semantic HTML for proper structure
  • Keyboard navigation support
  • Alt text for images
  • Color contrast ratios meeting WCAG standards
  • Skip navigation links
  • ARIA labels for interactive elements
  • Focus indicators for interactive elements
  • Responsive design for various screen sizes
